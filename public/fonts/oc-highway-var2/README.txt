FAQ
WHAT'S THE DIFFERENCE BETWEEN VAR.2 and VAR? 
The main difference is the addition of a new Grade axis. 

WHAT'S GRADE MEAN? 
“Grade” (GRAD in CSS) is an axis found in some variable fonts that can be used to alter stroke thicknesses without affecting the type’s overall width, inter-letter spacing, or kerning—unlike altering weight. This means changing grades will not affect the length of text and there are no changes to line breaks or page layout.You can read more in the Specimen PDF. 

SO OTHER THAN THAT THEY'RE THE SAME? 
Mostly but there have been improvements to some kerning pairs and the curly comma and colon Alternate Set [.ss01] has been expanded to include quote marks as well. 
Oh the another difference is the Oblique Axis values have been changed from 0-18. 

SO CAN I CAN STRAIGHT REPLACE THE OLD FONT WITH THIS NEW VAR.2? 
You should be able to yes, but if you have a document already set up with Highway VAR using Obliques they might get a bit messed up. But, for example, the Specimen PDF was originally set up with Highway VAR and we switched those fonts out for the equivalent styles of Highway VAR.2 and there were no noticeable issues. 

WHAT'S THE DEAL WITH THE FOLDER SYSTEM? 
Well there are 54 styles so just trying to organize them so you can get the ones you need. 
OG = Original Grade, which is the same line weight as Highway VAR
G-1 = The first static grade down, it's a bit thinner. 
G-2 = The second grade down which is thinner still. 

AND THERE ARE STATIC AND VARIABLE FILES FOR PRINT AND WEB? 
Yes. 

------

WHAT'S A VARIABLE FONT ANYWAY? 
Variable fonts are an evolution of the OpenType font specification that enables many different variations of a typeface to be incorporated into a single file, rather than having a separate font file for every width, weight, or style.

OC Highway VAR2 is a variable font with three axes:
  WIDTH (wdth)
  OBLIQUE (oblq)
  GRADE (grad)

All of the styles of the font are contained in two single files:
  OCHighwayVAR2VF.ttf for desktop
and
  OCHighwayVAR2VF.woff / .woff2 for web

If your app fully supports variable fonts, you can now seamlessly pick intermediate styles that aren’t available as static fonts. Not all apps support variable fonts, and in those cases you can use the static font files. If your software doesn't support the installation of variable fonts install the OTF files found in the STATIC Folder. 



HOW DO I GET STARTED?
1. Install the font files you want to use

2. Use your app's font picker to view the font family and all the
available styles
