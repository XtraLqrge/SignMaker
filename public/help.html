    Welcome

    Make your own highway guide signs with SignMaker.

    Build a single sign or arrange several panels on a post. Add destinations, route shields, exit numbers, and arrows, then download your design as an image or an editable sign file.

    Start with a preset

    Open the Simple Exit preset and change the destination, exit number, and arrow. Make your first sign

    Build a sign face

    Arrange text, shields, and symbols in rows. Use a separate subpanel for each destination that needs its own layout. Build rows and blocks

    Show where the lanes go

    Add an Exit Only band, assign arrows to individual lanes, or draw a junction or roundabout. Choose a guide arrow type

    Save your work

    Save a layout as a template for the next sign, or download this sign to edit or share later. Export a sign or post

    What is SignMaker?

    SignMaker is a tool for designing highway guide signs. A sign is made up of one or more panels on a post. Each panel contains subpanels, each subpanel holds rows, and each row holds blocks, such as a line of text, a shield, an arrow, or an icon.

    The toolbar

    • Panels. Add, duplicate, hide, and reorder panels. The button shows the selected panel’s name.
    • Panel Style and Post Style. Change a panel’s color, border, and padding, or choose the post that holds it.
    • Exit Tabs. Add exit numbers to the selected panel.
    • Subpanels. Build what the panel says, row by row and block by block.
    • Guide Arrows. Add arrows, Exit Only bands, lane arrows, junction diagrams, and roundabouts.
    • Templates. Start with a preset or save a sign you want to reuse.
    • Copy Sign, Export, and Import. Copy or save a sign as an image or an editable file, or open a saved sign.
    • Light Mode, Settings, and Hide Menu. Change how SignMaker looks and works.
    • Undo, Redo, and Clear All. Step back and forward through your changes or start over.

    SignMaker saves your work in this browser as you go. To edit the sign on another device, save an editable JSON copy.

    Make your first sign

    Start with the Simple Exit preset, change the destination, and export the sign. This takes you through the main editing tools.

    1. Open a preset. In Templates → Presets, find Simple Exit and load it. If you already have work on the canvas, export it first or save it as a template.
    2. Change the destination. Click the destination in the preview or find its Control Text block in Subpanels. Change Content to your destination.
    3. Set the exit number. Open Exit Tabs, select the tab, and edit its Text field. Use the alignment buttons to place it at the side you want.
    4. Check the arrow. Open Guide Arrows → Standard Arrows. Pick an arrow and adjust its position or angle. Some artwork already has a fixed direction.
    5. Download the result. Open Export to inspect the preview. Download PNG to share an image and JSON to keep an editable copy.

    Start without a preset

    Edit a new panel in Subpanels. Put the destination in a Control Text block, add another row, and put an Advisory Message in that row for the distance. Add a Shield block if the sign identifies a route. Finish the face in Panel Style and the direction in Guide Arrows.

    Next Select and edit on the canvas

    Select and edit on the canvas

    Select what you want to change on the sign or use the toolbar to jump to an editor.

    • Panel and support. Use Panels to select a sign face. Click the visible support to open Post Style.
    • Text or artwork. Click a destination, shield, or other block to select it in Subpanels. The row and block labels in the editor show what you are editing. Use them when items overlap in the preview.
    • Exit numbers and guide arrows. Clicking an exit tab or an arrow opens its editor. In Diagrammatics, the road-shaped arrow has its own editing handles and view controls.

    Make room to see the sign

    Use Hide Menu to see more of the preview. If opening a side editor makes the sign smaller, look for Shrink signs to fit panels in Settings. UI Scale changes the interface and its controls.

    Confirm what is selected

    SignMaker can flash the selected item. Turn on Show Block Bounds to inspect the areas occupied by blocks. Both options are in Settings → General → Interface.

    See also Use SignMaker on a phone · Draw diagrammatic arrows

    Undo, redo, and start over

    Use the history buttons to move through your edits. Keep an editable export when you want a checkpoint you can reopen later.

    Undo
    Step back one edit. On a keyboard, use Ctrl or Command + Z.
    Redo
    Reapply an edit you just undid. Use Ctrl or Command + Shift + Z, or use the Redo button.
    Clear All
    Start over on the current canvas. Export JSON first if you want to keep the sign as a file.

    A completed drag, a template choice, or a slider adjustment can be one undo step. To undo text you are still typing, use the field’s own editing shortcuts. SignMaker’s keyboard mode and shortcuts are under Settings.

    See also Keep editable copies · Keyboard shortcuts

    Add and organize panels

    Use a separate panel for each sign face you want to position independently on the post.

    1. Open the panel selector. The toolbar button is labeled with the current panel, such as Panel 1.
    2. Select a panel in the list. Use the add controls to create a panel or duplicate an existing one if you want to keep its format.
    3. Use the panel’s visibility control to hide it while keeping it in the project. Use the delete control to remove it.

    Arrange the signs

    On desktop, drag a sign face left or right to reorder it. The insertion marker shows where it will land. Drag up or down on supported posts to change the mounting offset. The dominant drag direction determines which action starts. A stack moves as a unit.

    When panel edges or centers line up, SignMaker shows a snap guide. Hold Alt or Option to bypass snapping. Press Escape during the drag to cancel it.

    See also Stack panels · Choose a post or support · Use SignMaker on a phone

    Stack panels

    Use a stack when separate sign faces should sit above or below each other, such as a toll notice above a destination sign.

    1. Select the main panel and open Subpanels.
    2. Use Add Panel Above or Add Panel Below. Select an item in the panel strip to edit that face. The strip identifies the Main Panel and the added faces.
    3. Open the stack options from the chevron to adjust spacing or match the widths. Inspect the preview after changing the content of a stacked panel.

    Choose between a stack and a row

    A stack gives each face its own panel styling and content. A row keeps the content within the same face. If you want a colored message band inside the sign, add a row and use Row Properties before adding a whole panel.

    See also Space and color rows and blocks · Export a sign or post

    Style a panel

    Open Panel Style after selecting the face you want to change. Use Appearance for the face and border, and Padding for the space around its content.

    Set the panel dimensions

    At the bottom of Panel Style → Appearance, enter Set Width, Set Height, or both. Clear either field to return that dimension to automatic sizing. These fields apply to all panel types and take priority over the diagrammatic editor’s dimensions.

    The measurements cover the sign face and its built-in arrow bands. Exit tabs, the outer border, and VMS housing add to the outside size. Content that extends past the face is clipped, so use the preview to check that everything fits.

    Change the face and border

    • Panel color. Choose a preset or use the color picker for a custom color. Look at the preview to check text and border contrast.
    • Corners and shape. Choose a corner style and adjust Border Radius for the curve you want. Enable Warning Diamond for a diamond-shaped face.
    • Border. Set the color and thickness. Inherit follows the panel’s color rules. Outer Border adds a rim outside the main border and increases the outside size.

    Adjust space around the content

    Set the top, right, bottom, and left padding independently. Measurements marked rem use SignMaker’s layout scale. Use Reset to Default to restore the padding values.

    To move a single line or block, use its own row or block properties. To add more space between separate sign faces, change panel spacing in Post Style.

    See also Space and color rows and blocks · Make a VMS panel

    Choose a post or support

    Open Post Style from the toolbar or click the support in the preview. These changes apply to the whole assembly.

    1. Choose a Post Position, then select a compatible Post Type. Changing position can select that position’s standard support.
    2. Use Post Color and Post Thickness to adjust the appearance. Use Hide Post to see the faces by themselves.
    3. Set Panel Spacing for the current assembly. Default Panel Spacing sets the starting value for new work.

    Use an FDOT preset

    Look in the FDOT group in Post Type. Options depend on the position. Presets include ground posts, cantilevers and spans, overhead trusses, walk-in message sign supports, mast arms, and span wires. The support drawing follows the size of the sign assembly.

    Use Entire Post in the export preview when you want the support in the image. The support drawings illustrate the appearance of the assembly.

    Work with subpanels

    A subpanel organizes related information inside one sign face. Give each destination its own subpanel when the destinations need separate columns or lane arrows.

    1. Select the sign face, then open Subpanels.
    2. Choose a subpanel in the top strip. Use the add or duplicate button to make another subpanel. Use the delete control beside a subpanel to remove it.
    3. Build the selected subpanel in the rows and blocks editor. Preview any divider between adjacent subpanels to check where the columns separate.

    Add a header or footer

    Use Add Header or Add Footer for content that runs above or below the subpanels. Choose a block type in that picker, then edit it from the Top or Bottom tab. A regular row belongs to a single subpanel.

    Place a subpanel on a diagram

    In Guide Arrows → Diagrammatics, choose Place subpanel from the editor’s add menu. Click to place a default subpanel or drag a box to set its size. Drag a subpanel to move it. While editing diagrammatic arrows, click once to select its assembly and click again to open its contents.

    See also Build rows and blocks · Align a diagram

    Build rows and blocks

    Put items side by side with blocks in one row. Add another row for items that need to sit underneath.

    1. In Subpanels, select the subpanel you want to edit. The row list shows which blocks are already in it.
    2. Select a row or use the row toolbar’s New button to add one. Duplicate copies the selected row.
    3. Choose the block type in the New picker next to the block controls, then click Add. Select its label to show its own editor.
    4. Drag a row or block when the editor offers a reorder handle. Use the delete icon on the appropriate label to remove just that item.

    Common block types

    • Text for destinations, distances, and driving instructions.
    • Shield for a route number and its artwork.
    • Arrow, Icon, Toll Logo, Divider, and Flashing Beacon for symbols, payment instructions, and separators.
    • Variable Message for a message in an electronic display within a larger sign.

    See also Group and reuse blocks · Space and color rows and blocks

    Edit sign text

    Select a text block and edit Content. Use the block type that best describes the message.

    Control Text
    A main place or destination, such as Detroit or Airport Road.
    Advisory Message
    Distance or advance notice, such as ½ MILE or EXIT AHEAD.
    Action Message
    An instruction or other short message. Set the colors and size for the treatment you want.

    Set the type and spacing

    Use the font picker to choose a face. Adjust the size, alignment, letter spacing, and line height in the text editor. Use Side Spacing to adjust the space beside the text element. When available, Enlarge Numerals, Small Letters, and banner options change how selected characters are treated.

    Use separate rows when two lines need independent alignment or styling. For a distance like ½ MILE, enter the fraction character and review how the chosen font displays it.

    See also Choose fonts and colors · Make a street-name sign

    Choose fonts and colors

    Font and color controls appear where they apply. Use the text block’s controls for its lettering and Panel Style for the sign face.

    Find a typeface

    • Search the font picker by family name or series, such as Series E. The preview uses the selected face.
    • In the simplified mobile picker, choose Highway Gothic or Clearview. Open Advanced… or enable Advanced dropdowns in Settings to choose a specific series.
    • Enable Highway VAR fonts in Settings → General to add that family to the picker.

    Choose or reuse a color

    Pick a preset swatch or open the custom color controls where available. An Inherit setting lets the surrounding sign or row supply the color. Match BG follows the background for that control. Choose an explicit color when the preview should stay the same after you change the panel.

    See also Style a panel · Change the interface

    Add route shields and banners

    1. Add a Shield block in Subpanels. Open the shield picker and search for the route system or region.
    2. Enter the route number. Leave Variant on Auto when it is available and the digit count should choose the artwork. Choose another variant when you need a specific shape. Some shields use fixed artwork.
    3. Set the shield size and alignment. Use Show TO for a connecting route, and the county or road-name fields when the chosen shield or layout calls for them.

    Put text around a shield

    Enter text in Banner 1 or Banner 2, then choose which side of the shield the banner sits on. Set the banner’s font, size, and color if needed. Leave the field empty to remove a banner. Scale banners makes banners follow the shield’s sizing.

    Open Settings → Shields to organize the shield picker. Drag an item by its grip to reorder it. Drop it on the center of a folder to move it inside, or on ↑ Up to move it to the parent folder. Select any item to see its other controls.

    If adjacent shields show the same upper banner, Settings → General → Join Matching Banners controls whether they share it.

    See also Make a custom shield · Add toll logos and symbols

    Make a custom shield

    Click Edit shield in a shield block to open the Custom Shield Maker with that shield.

    Use the Custom Shield Maker from the shield picker to reuse your own shield artwork with editable route numbers.

    1. Name the shield and select the digit variant you want to work on. Choose the base artwork or upload an image for that variant.
    2. Use the sample Route Number to check the artwork. Set the font, color, and text alignment. Adjust the font size, letter spacing, and horizontal or vertical offsets.
    3. Review the image in the preview and repeat for any other variants you need. Save the shield, then choose it in the shield picker.

    To place existing artwork as an image, use the shield selector’s Custom area to upload it or enter an image URL. The shield maker’s JSON buttons save or open an editable shield as a reusable asset. Use the main SignMaker Export menu to save the sign that uses it.

    See also Add route shields and banners · Open an editable sign file

    Add arrows, icons, and dividers

    These items live in a row alongside text or shields. Put an item in its own row when it needs its own height or background.

    Arrow
    Choose an arrow image, then set size, rotation, and alignment. Use the angle buttons for common directions and flip the artwork where the option is available.
    Icon
    Open Choose Icon. Search built-in symbols or use Upload Icon for an SVG, PNG, or WebP file. Sort uploaded images or switch between grid and list view. Adjust the chosen icon’s size, background, or border in the block editor.
    Toll Logo
    Open Choose Logo and select the agency or payment mark. You can give the logo a background or a square treatment in the block controls.
    Flashing Beacon
    Set the beacon’s size, color, and alignment. Choose a backplate or use Flash Opposite to alternate its flashing phase with another beacon.
    Divider
    Choose its orientation and size. Use a full-bleed setting when a separator needs to reach the edge of its available area.

    Use Guide Arrows when the arrow belongs to the panel as a whole or must line up with a travel lane.

    See also Choose a guide arrow type · Space and color rows and blocks

    Space and color rows and blocks

    Select an item in Subpanels and expand Block Properties or Row Properties to edit the selected item.

    Control areaUse it for
    Block PropertiesMargins around one block, its background and border, and its width.
    Row PropertiesTop and bottom margins around the selected row, left and right padding inside it, and the row’s background, border, and width. Turn on Full border to outline the row on all four sides.
    Panel Style → PaddingSpace between the overall face or border and the content inside it.
    Post Style → Panel SpacingSpace between separate panels on the same post.

    Make a colored band

    Put the message in its own row. Open Row Properties and set BG to color the band. Set Border to choose its border color. Use the text block’s lettering color to get the contrast you want.

    Keep a row or block flexible

    Set its width to 0 to let it size itself. Use a fixed value when you need a particular width. If a block looks off-center, check its margin and alignment before changing the whole row.

    Group and reuse blocks

    Group blocks that should move together, such as a logo and a payment message.

    1. In the desktop block editor, hold Ctrl or Command and click the blocks to select them. Use Shift-click to select a range.
    2. Choose Group selected. Select the resulting group and choose Edit contents to work on the individual blocks.
    3. Use the group’s alignment, background, border, and corner controls to style it as a unit. Use Ungroup to return to individual blocks.

    Reuse part of a sign

    Use Duplicate on a row or block for another copy in the editor. Use the block context menu and Copy, Cut, Paste, or Paste after to move or copy elements across compatible rows or subpanels. Check the target row and block before pasting.

    See also Keyboard shortcuts · Save a panel or post template

    Make a street-name sign

    Use separate text blocks when a direction or suffix needs a different size than the main street name.

    1. Enter the main street name in a Control Text block.
    2. Add another text block for a direction or suffix, and place it in the same row as the main name. Adjust that block’s size and alignment separately.
    3. Check the spacing in the preview. Adjust the margins on a single block or use Panel Style padding to set the space around the whole name.

    See also Edit sign text · Style a panel

    Make a VMS panel

    A variable message sign (VMS) panel treats the whole face as an electronic display.

    1. Select the panel and open Panel Style.
    2. Choose Switch Panel to VMS. Use the VMS appearance controls to adjust LED Resolution, antialiasing, and the frame.
    3. Edit the panel’s content in Subpanels. Use the preview to check message length and readability at the intended display size.

    Use the frame settings for the whole display. To place only one electronic message on a conventional sign face, use a Variable Message Sign block.

    Add a variable message block

    Add a Variable Message block to place an electronic message within a row, alongside ordinary messages or symbols.

    1. Enter the message and choose its font, size, color, and alignment. Adjust line height when you use multiple lines.
    2. Use Realistic LED for a pixelated look and LED Resolution to set the detail. Toggle Glow if you want a lit effect.
    3. Leave Set Width at 0 to fit the text. Enter a width to keep the display area consistent between messages.

    On a VMS panel, the panel’s LED settings control the final appearance. The block’s own LED settings apply on a conventional face.

    Add and position exit tabs

    Open Exit Tabs on the selected panel to edit the small sign or label that identifies an exit.

    1. Select a tab in the list, or use + to add one. Enter the label in Text. If a standard tab is empty, it may stay hidden until you enter text.
    2. Pick a type and choose the placement and width. Available settings depend on the type and the sign’s arrow layout.
    3. Adjust the font, text spacing, text and background colors, border, minimum height, and padding. The corner radius can follow the sign face or use a custom value.

    Work with more than one tab

    Use the tab list to select, duplicate, or remove tabs. Use Nest Exit Tab to attach a tab to the selected tab. Adjust Nested Tab Spacing if the attached tabs need more room. Review placement again after changing a panel’s width or subpanels.

    See also Choose an exit tab type · Reuse exit tab formatting

    Choose an exit tab type

    Use the type picker next to the exit tab text. Choose the artwork and layout first, then set the placement.

    Type or optionUse it for
    StandardAn ordinary text tab, such as EXIT 24A. Use width and position to fit the tab to the face.
    CaliforniaAn inset tab at the top-left or top-right corner of the sign. The inset type controls its position. Use the available alignment and sizing options.
    Full Left and StackedA left-side label or a stacked exit layout when the text needs a different arrangement.
    Toll Logo and IconArtwork in the tab. Use the chooser that appears for the type and adjust the asset size.

    Choose Quebec Exit Marker in the exit tab type picker. Enter the number to place it alongside the guide arrows or at the bottom of the panel.

    Vertical Arrangement and bilingual text controls appear where supported. If a setting is unavailable, check the selected tab type and its placement.

    Reuse exit tab formatting

    Use an exit tab profile when several tabs should share the same formatting.

    1. Open Exit Tabs → Profiles to manage available profiles. Choose a profile and the relevant tab type when editing its settings.
    2. Return to Current Panel and select the tab. Choose the profile in the Profile picker.
    3. Enter the exit number or message for this tab. Review other tabs that use the profile before changing its shared formatting.

    A profile is for exit tab formatting. Save a panel as a template when you also want its rows, colors, and guide arrows.

    Choose a guide arrow type

    Open Guide Arrows for arrows and lane layouts attached to the panel. Use an Arrow block in Subpanels when an arrow belongs in a particular row.

    EditorChoose it when
    Standard ArrowsYou need one or more arrows pointing in known directions.
    Exit OnlyThe sign needs an exit-only band, wording, arrows, or a partial or split treatment.
    Arrow-Per-Lane (APL)Each arrow should line up with a lane or a lane group, and the layout may have a split or turn.
    DiagrammaticsThe arrows should show a junction with drawn stems, branches, and lane markings.
    RoundaboutThe destinations should be placed around a roundabout or right-turn bypass graphic.

    Diagrammatics and Roundabout are on the second row of Guide Arrows tabs. Use the preview as you switch types, since they organize the content in different ways.

    Set standard arrows

    1. Open Guide Arrows → Standard Arrows. Choose artwork in Arrow and set the count.
    2. Set the angle, size, padding, and spacing as applicable. Choose an alignment and a position for the arrow area.
    3. Open Individual arrows to give a particular arrow a different type or direction where the layout supports it.

    When a control is disabled

    Some arrows have a built-in direction, and spacing only applies when the layout has room to separate multiple arrows. Choose arrow artwork with the direction you want, or use the individual controls for one arrow in a group.

    See also Add an arrow in a row · Make an Exit Only band

    Make an Exit Only band

    Use the Exit Only editor to identify lanes that leave the highway.

    1. Open Guide Arrows → Exit Only. Choose the band style for the lane layout, such as Exit Only, Half Exit Only, or Split Exit Only.
    2. Set the arrow type and direction in Arrows. Use the available placement and size controls.
    3. Use Text and Background to adjust the wording and band styling. Review the layout after changing the arrow direction or the number of lanes.

    Use Arrow-Per-Lane if the sign should have a separate exit-only treatment tied to a lane arrow.

    Set arrow-per-lane layouts

    Use APL for overhead layouts in which each arrow identifies a specific lane or lane group.

    1. Create at least two subpanels or use a preset such as Standard APL. Opening the APL tab on a single subpanel can offer to add a second one.
    2. Open Guide Arrows → Arrow-Per-Lane (APL). Add or select a lane arrow. Choose the shape, such as through, turn, or a combined movement.
    3. Use the lane controls to place the arrow in its subpanel or at the supported divider position. Adjust size, spacing, and Exit Only where those controls apply.

    Use the destination text and shields in each subpanel to label the lanes. On a phone, use the lane rows and their pickers to assign arrows.

    See also Work with subpanels · Draw arrow branches and lane lines

    Draw diagrammatic arrows

    Use Guide Arrows → Diagrammatics for a drawn junction. The first switch adds a straight two-lane arrow. You can choose Straight, Left fork, Right fork, or Y split before customizing it.

    Draw or connect a stem

    1. Choose the arrow stem in the add menu and start drawing. Click where it should start, then click again to place the next point. A new standalone stem starts straight up. Hold Shift while drawing to choose a different direction.
    2. Continue clicking to add segments. Start or end near an existing lane endpoint or edge to connect a branch. Double-click or press Escape to finish drawing.
    3. Select a stem to change its lane count, lane width, curve, or arrowhead size. Use the lane node menu for taper and connection controls, or to change overlap order where stems cross.

    Move or shape the arrows

    • Move an assembly. Drag the body of a stem to move all the stems connected to it. Use Move assemblies to move the entire drawing.
    • Move one end. Drag a lane node to adjust that endpoint. Use the curve controls to change the bend or radius.
    • Straighten a path. With Straighten on Shift-click enabled, click a lane node, then Shift-click another node on the connected path.

    Use Consistent gaps on turns to keep dashes in step through curves. Use the diagram editor’s JSON controls to exchange the arrow drawing by itself.

    See also Align and resize a diagram · Make a roundabout sign

    Align and resize a diagram

    Keep Snap to align enabled while positioning arrows or subpanels. Guides appear when an item is close enough to an alignment.

    Line up labels
    Drag a subpanel near another subpanel or the panel’s center. Snapping lines up edges and centers.
    Match branches
    Drag an endpoint close to the mirrored position across the junction. Snapping can match the angle and length of nearby stems too.
    Point straight up
    Drag an endpoint near the vertical line from its other end. Hold Alt or Option while dragging to bypass alignment.
    Resize the face
    Drag an edge or corner of the panel while the Diagrammatics editor is open. You can also enter Width and Height. Select a placed subpanel to resize it with its own handles.

    Zoom while you edit

    Use + and − or the editor’s scroll controls. Choose Fit or press F when you want the normal view. Closing Diagrammatics returns the preview to its normal framing. Reopen it to continue at your editing zoom.

    Make a roundabout sign

    1. Open Guide Arrows → Roundabout. Choose D1-5 for a roundabout or D1-5a for a right-turn bypass.
    2. Set Assembly size and adjust sign padding on each side.
    3. Enable the exits you need. Use Edit destination beside an exit to open the corresponding subpanel.

    Left, Thru, and Right use subpanels 1, 2, and 3 respectively. Use those subpanels for the corresponding text and shields. Check the preview when you change which exits are shown.

    Use and save templates

    Use a preset to start with a working layout, or save your own panel or post for later.

    Start with a preset

    1. Open Templates → Presets. Search by name, such as Simple Exit, Mileage Sign, Standard APL, or VMS.
    2. Choose the load or replace action for the item. Check whether it will affect the whole post or just the selected panel.
    3. Edit the resulting sign on the canvas. Choose Edit on a preset when you want to create a reusable customized version.

    Save your own layout

    Open Templates → Saved, enter a name, and choose Save Panel for the selected face or Save Post for the assembly. Use search or sort to find it again. Turn on Confirm before replacing a post or panel if you want a prompt before loading a template over your work.

    See also Edit templates and variants · Keep editable copies

    Edit templates and variants

    A template can keep several versions of the same layout, such as versions with different lettering.

    1. In Templates, choose Edit on a saved template or preset. The canvas becomes the working view for the selected version.
    2. Choose Version Being Edited. Adjust the layout on the canvas or set Variant Font and use Apply Font.
    3. To add another variation, enter its name, choose a font if needed, and click Add Variant. Review the active version before deleting one or switching.
    4. Use Save & Exit to keep the changes. Use Cancel to leave the editor without saving them.

    The editor captures the current canvas when you switch versions or save. Finish editing the template before importing a different sign file.

    Keep editable copies

    SignMaker automatically saves the current work in the browser you’re using. Download JSON when the design needs to travel with you.

    MethodBest for
    Automatic saveReturning to the current canvas in the same browser and profile.
    Saved templateReusing a layout from the Templates menu in that browser.
    Export JSONKeeping a backup, sharing an editable design, or continuing on another device.
    Export PNG or SVGUsing the design as artwork. SignMaker’s own SVG can reopen in the editor while its embedded sign data is intact.

    Use Settings → General → On refresh to restore the last sign, ask first, or start a new sign. Separate browser profiles keep separate copies. Clearing site data can remove local work and templates.

    See also Export a sign or post · Open an editable sign file

    Export a sign or post

    1. Open Export and review the preview. Keep Entire Post selected when you want the assembly, including the visible support. Turn it off and select the panel or panels to export their faces.
    2. Choose a format. Use Image Resolution when you need a larger PNG.
    3. Use a download button to save a file or a copy button to send it to the clipboard where supported.
    FormatUse
    PNGA raster image for sharing or inserting in a document. Higher resolution means a larger file.
    SVGA scalable graphic. SignMaker adds editable project data to its own SVG exports.
    JSONAn editable sign file for importing into SignMaker.

    Enable Export without panel background in Settings to leave out the panel fill, borders, exit tab fills, and row bands in images. Check the preview before saving.

    Copy a sign to the clipboard

    Use Copy Sign for a quick PNG copy. Paste the image into a message, document, or other app that accepts images.

    • Right-click Copy Sign on desktop to choose a particular panel.
    • Use Settings → General → Copy Signs Only to control whether the quick copy omits the support.
    • For a particular export format or panel selection, use the copy actions in Export.

    If the browser refuses a clipboard request, bring the SignMaker window to the front and try again. Download the image and attach it if the destination does not accept the clipboard format.

    See also Export a sign or post · Copy editable blocks

    Open an editable sign file

    1. Save the current canvas if you want to keep a separate copy. Close the template editor if it is open.
    2. Choose Import on the toolbar. Select a SignMaker JSON file or an SVG exported by SignMaker that still contains its sign data.
    3. Review the imported canvas. Use Undo to restore the previous canvas after a successful import.

    A plain SVG or PNG does not contain the editable panels and blocks. Use the icon or shield image controls if you want to add artwork from a separate file.

    The Shield Maker and Diagrammatics have their own JSON tools. Open a shield or arrow graph in the matching editor.

    Change the interface

    Open Settings → General → Interface to change how SignMaker looks and responds. Preferences are saved in the current browser.

    Theme and toolbar
    Use System, Light, or Dark and choose the toolbar position where available. Adjust UI Scale or Text Size when the controls are hard to read. The UI Scale slider shows the selected percentage as you drag and resizes the interface when you release it.
    Preview space
    Use Shrink signs to fit panels to make room for open editors. Use Hide Menu to see the canvas with fewer controls.
    Editing feedback
    Control selection flash, block bounds, alignment guides and their spacing, and interface animations.
    Pickers and fonts
    Enable Advanced dropdowns for the full mobile pickers. Use Enable Highway VAR fonts to show that family in font lists.
    Restore, copy, and export
    Choose what happens On refresh, whether quick copies include the support, and whether exported images omit the panel background.

    See also Set defaults for new signs · Keyboard shortcuts

    Set defaults for new signs

    Use Settings → Defaults to set the starting choices for new text, shields, arrows, and other elements.

    1. Select the category you want to change. Use its controls to choose a starting type, size, color, or other available value.
    2. Create a new block or panel to see the default in use. Edit existing items in their own editors when their stored values need to change.
    3. Use the profile controls to import or export a defaults profile. Use the reset action to return to the supplied choices.

    Use Exit Tabs → Profiles for shared exit tab formatting. Save a complete layout as a template when you want to reuse its arrangement as well.

    Use SignMaker on a phone

    Use the bottom toolbar to open editors. Tap the part of the sign you want to change to open the corresponding editor below the preview.

    • Choose a panel. Open the panel list and use Show entire post to see all the panels together. In the whole-post view, touch and hold to enter reorder mode, then drag a panel into position.
    • Edit a block. Use Blocks to choose the subpanel, row, and block. The compact editor keeps the selected element’s controls together.
    • Find the tools. Style opens Panel Style, and Arrows opens Guide Arrows. Use the additional actions menu for less common tools.
    • See all choices. Open Advanced… in a simplified picker or turn on Advanced dropdowns in Settings.
    • Check export scope. Open Export and inspect its preview before downloading, especially after changing between a single panel and the whole post.

    Troubleshoot common problems

    The wrong item is changing.
    Check the active panel, subpanel, row, and block labels. A panel has its own style and arrows, while Post Style applies to the whole assembly. Review the sign structure.
    An arrow or exit tab is missing.
    Check the selected panel’s Guide Arrows type, arrow count or enabled lanes, and the exit tab’s text and placement. Empty standard exit tabs can be hidden. Review arrow types.
    A font, color, or arrow is missing from a phone picker.
    Open Advanced… or enable Advanced dropdowns. For Highway VAR, enable its own Settings switch. Review fonts and colors.
    The image is missing the post or some of the panels.
    Check Entire Post, the export panel selection, and whether the support or a panel is hidden. Review the export preview before saving. Review export options.
    I cannot reopen an image as an editable sign.
    Use a SignMaker JSON export or a SignMaker SVG with its embedded sign data. A PNG or a plain SVG is artwork. Review editable imports.
    My last sign did not return after refreshing.
    Check On refresh and confirm you are using the same browser and profile. Import your JSON backup if local site data was cleared. Review backup options.
    Clipboard copy failed.
    Bring the SignMaker window to the front and try again. Use Export to download a file if clipboard writing is unavailable. Review clipboard copying.
