Welcome to SignMaker

Riverside ↑

Design highway signs with your own destinations, route shields, and arrows. Try editing this sample sign to learn the basics.

1. Edit the destination

Select text on a sign, or open Subpanels (Blocks on mobile) and choose a Control Text block. Try changing the sample destination.

2. Set the direction

Open Guide Arrows (Arrows on mobile) to choose an arrow and set its angle. Give the sample sign a direction.

3. Save your sign

Open Export (under More on mobile) to save a PNG or SVG image. Choose JSON if you want to reopen the file and keep editing.

Use the Help button beside Undo to find more examples and editing tips.
